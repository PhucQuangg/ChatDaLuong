Mục tiêu chính của đề tài là nghiên cứu và ứng dụng công nghệ để xây dựng hệ thống chat đa luồng trong nền tảng thương mại điện tử, giúp cải thiện khả năng tư vấn khách hàng tự động, đồng thời đảm bảo hệ thống có kiến trúc linh hoạt, dễ mở rộng. Các mục tiêu cụ thể bao gồm:
•	Nghiên cứu về Django REST Framework (DRF): hiểu rõ kiến trúc, nguyên tắc hoạt động và cách xây dựng API RESTful sử dụng DRF.
•	Xây dựng API hoàn chỉnh cho website bán hàng: thiết kế và phát triển API hỗ trợ các chức năng cơ bản của một website thương mại điện tử.
•	Tích hợp chat đa luồng theo mô hình N-1: Sử dụng WebSocket/Django Channels để thiết lập kênh giao tiếp thời gian thực giữa nhiều người dùng và một admin hỗ trợ.
•	Ứng dụng AI vào hệ thống chat: tích hợp API Cohere AI vào hệ thống để hỗ trợ khách hàng tự động khi admin không có mặt.

Phạm vi thực hiện
•	Sử dụng Django REST Framework (DRF) phát triển backend: xây dựng API để quản lý dữ liệu và hỗ trợ giao tiếp với hệ thống chat.
•	Tích hợp chat real-time theo mô hình N-1: Sử dụng WebSocket và Django Channels để triển khai hệ thống chat, đảm bảo nhiều khách hàng có thể trò chuyện với một admin cùng lúc.
•	Quản lý dữ liệu bằng cơ sở dữ liệu: sử dụng PostgreSQL hoặc SQLite để lưu trữ thông tin đảm bảo dữ liệu có tính nhất quán và dễ truy vấn.
•	Ứng dụng AI vào chatbot: gọi API Cohere dể chatbot có thể xử lý các yêu cầu của khách hàng một cách tự động.
•	Tối ưu hiệu suất: đảm bảo hệ thống chat có thể xử lý nhiều yêu cầu cùng lúc, phản hồi nhanh, giảm tải cho máy chủ.
